# Инструкция по управлению сайтом Northern Magical Place

Сайт: [https://northmp.su](https://northmp.su)  
Админка: [https://northmp.su/admin.html](https://northmp.su/admin.html)

---

## 1. Вход в админку

1. Откройте `/admin.html`
2. Введите **логин** и **пароль** из файла `.env` на сервере:
   - `ADMIN_USER`
   - `ADMIN_PASSWORD`
3. Нажмите «Войти»

Сессия хранится только в браузере. Не публикуйте логин/пароль и не коммитьте `.env` в Git.

В админке слева меню в стиле Bitrix24:

| Раздел | Пункты |
|--------|--------|
| **Контент** | Товары, Новости, Отзывы, Страницы, Тексты сайта |
| **Магазин** | Заказы, Заявки |
| **Маркетинг** | Акции |

Внизу меню: «Открыть сайт» и «Выйти». На мобильном меню открывается кнопкой ☰.

Изменения в CMS сразу видны на витрине и участвуют в расчёте оплаты.

## 2. Товары

### Добавить товар

1. Вкладка **Товары** → **Добавить товар**
2. Заполните:
   - **ID** — уникальный (например `5`)
   - **Артикул (SKU)** — например `NMP-XX-05` (уйдёт в заказ и СДЭК)
   - **Slug** — латиницей для URL
   - **Название, цена, описания**
   - **Доступен к заказу** — если снять галочку, вместо «Оформить заказ» будет кнопка **«Сообщить о поступлении»**
   - **Характеристики** — каждая с новой строки
   - **Главное фото** и **галерея**
3. Сохраните

Заявки на оповещение смотрите во вкладке **Заявки**.

### Изменить цену

Откройте товар → поле **Цена, ₽** → Сохранить.  
Именно эта цена (или акционная, если включена) уходит в ЮKassa.

### Акционная цена на товар

В карточке товара:

- **Акционная цена**
- галочка **Акционная цена активна**
- **Текст акции на товаре** (плашка, например `−10%`)

На витрине будет зачёркнутая базовая цена и новая сумма.

### Фото и доп. фото

1. В форме товара нажмите выбор файла у «Главное фото» или «Галерея»
2. Файл загрузится в `images/uploads/` и путь подставится автоматически
3. При загрузке фото **автоматически оптимизируется** под витрину: ориентация по EXIF, длинная сторона ≤ 1600px, сжатие (обычно WebP; PNG с прозрачностью остаётся PNG)
4. В галерее — **каждый путь с новой строки**

На карточках каталога и странице товара фото показываются целиком (`object-fit: contain`), без обрезки краёв.

### Живое превью карточки

При редактировании товара справа (на телефоне — сверху) сразу видно, как карточка выглядит **в каталоге** и **на странице товара**. Переключайте вкладки «Карточка каталога» / «Страница товара». На витрину это попадёт только после кнопки **Сохранить товар**.

### Характеристики / сценарии / FAQ / SEO

- Характеристики и сценарии — списки, **каждый пункт с новой строки**
- FAQ: строки вида `Вопрос || Ответ`
- SEO title / description — для поисковиков и соцсетей

### Скрыть товар

Снимите галочку **Показывать на сайте** — товар исчезнет из каталога, но останется в админке.

### Удалить товар

Кнопка **Удалить**. Осторожно: старые заказы с этим id останутся в истории, новый заказ с ним создать будет нельзя.

## 3. Акции и спецпредложения

Вкладка **Акции**:

- заголовок, текст, плашка;
- привязка к **ID товара** (ссылка ведёт на карточку);
- даты начала/окончания;
- галочка **Акция активна**.

Активные акции показываются полосой под героем на главной.

> Чтобы реально снизить цену в корзине — задайте **акционную цену в карточке товара**. Блок «Акции» — это маркетинговые анонсы.

---

## 4. Новости

Вкладка **Новости**:

- заголовок, краткий и полный текст;
- картинка (можно загрузить файлом);
- дата публикации;
- галочка **Опубликовано**.

Опубликованные новости появляются в блоке **Новости** на главной. Если новостей нет — блок скрыт.

---

## 5. Отзывы

Вкладка **Отзывы**:

- автор, подпись (город · товар);
- текст;
- оценка 1–5;
- порядок сортировки;
- галочка показа на сайте.

## 6. Страницы, тексты и контакты

### Картинки — вкладка **Страницы**

Список ключевых блоков сайта с превью и кнопкой **Заменить**:

- главный баннер (первый экран);
- «О нас»;
- стиль жизни (река, дом, озеро, кемпинг);
- фон каталога / преимуществ;
- фон блока контактов;
- фон внутренних страниц (доставка, эксплуатация, политика, гайды);
- логотип в шапке и подвале.

Как заменить:

1. Откройте **Страницы**
2. Найдите нужный блок и нажмите **Заменить**
3. Выберите JPG, PNG, GIF или WebP

Новый файл **конвертируется в WebP**, путь сохраняется в CMS, предыдущий загруженный файл удаляется. Стандартные картинки из `images/` не трогаются.

Шапка при прокрутке и подвал **сами берут фото главного баннера**. Если заменить баннер — верх и низ сайта подстроятся без отдельных настроек.

### Тексты — вкладка **Тексты сайта**

- H1 и подзаголовок героя;
- заголовки и лиды каталога, новостей, отзывов;
- «О нас», преимущества, стиль жизни, обратная связь;
- e-mail, телефон, ссылки Telegram / WhatsApp / MAX / Instagram.

Карточки товаров, новости и отзывы правятся в своих вкладках. Юридические тексты (`privacy.html`, `usage.html`) и длинные гайды остаются файлами сайта; у них общий фон из «Фон внутренних страниц».

## 7. Заказы

Вкладка **Заказы** — операционная панель:

- фильтры: все / к отгрузке / просрочено / оплаченные / без оплаты / в пути / отменённые;
- поиск по номеру, телефону, ФИО, треку, ПВЗ, SKU;
- в карточке заказа: статусы оплаты и сборки, товары с фото, клиент, ПВЗ и трек;
- **Подробнее по заказу** — суммы, тариф, комментарий, UUID СДЭК, ЮKassa и история событий;
- **Редактировать** — ФИО, контакты, ПВЗ, суммы, статусы;
- **Удалить** — безвозвратное удаление заказа;
- **Синхронизировать статусы** / **Обновить из ЮKassa / СДЭК** — подтягивает оплату и этап доставки;
- **Выгрузка в 1С** — CommerceML XML / CSV / JSON для обработки заказов в учётной системе.

| Действие | Когда |
|----------|--------|
| Синхронизировать статусы | Обновить сразу пачку заказов из ЮKassa и СДЭК |
| Обновить из ЮKassa / СДЭК | Один заказ |
| Скачать XML / CSV / JSON | Выгрузка заказов в 1С (оплаченные / в работе / новые / все) |
| Редактировать | Исправить данные клиента, ПВЗ, суммы, статусы |
| Удалить | Убрать заказ из базы |
| Сохранить заметку | Любые пометки по сборке |
| Отметить оплаченным | Деньги есть, webhook не сработал |
| Создать накладную СДЭК | Оплачен, накладной нет |
| Отметить: сдан в СДЭК | Посылка сдана |
| Отметить: прибыл в ПВЗ | Можно забирать |
| Отменить заказ | Клиент отказался / ошибка |

### Выгрузка в 1С

1. Откройте вкладку **Заказы**
2. Выберите набор: оплаченные / в работе / ещё не выгруженные / все
3. Скачайте нужный формат:
   - **XML (CommerceML)** — стандартный `orders.xml` для обмена с 1С
   - **CSV** — таблица с разделителем `;` (удобно открыть в Excel и загрузить обработкой)
   - **JSON** — для своей HTTP-обработки / внешней интеграции
4. При необходимости включите «Пометить как выгруженные в 1С»

API (с Bearer-сессией после входа):

`GET /api/admin/orders/export?format=commerceml|csv|json&scope=paid|processing|new|all&mark=1`

SLA отгрузки по умолчанию — 48 часов после оплаты (`SHIP_SLA_HOURS` в `.env`).

Статусы для клиента: Ожидает оплату → Сборка → Отправка → Прибыл / Отменён.

## 8. Как устроено технически (кратко)

| Что | Где хранится |
|-----|----------------|
| Товары, новости, отзывы, акции, тексты | `server/data/cms.json` (создаётся из `server/cms-seed.json`) |
| Заказы | `server/data/shop-orders.json` |
| Загруженные фото | `images/uploads/` |
| Секреты | `.env` (не в Git) |

Публичный API витрины: `GET /api/cms`  
Админский API: `/api/admin/*` (нужен Bearer-токен)

Папку **`server/data/`** нельзя терять при деплое — там CMS и заказы.

## 9. Оплата и доставка

### ЮKassa

В `.env`:

```env
YOOKASSA_SHOP_ID=...
YOOKASSA_SECRET_KEY=live_...
PAYMENTS_DEMO=false
PUBLIC_BASE_URL=https://northmp.su
```

Webhook в кабинете ЮKassa:  
`https://northmp.su/api/payments/webhook`  
события `payment.succeeded`, `payment.canceled`.

### СДЭК

Отправка из Петрозаводска, Лесной пр. 47.  
Клиент выбирает ПВЗ на оформлении заказа.

## 11. Частые вопросы

**Поменял цену в админке — на сайте старая**  
Обновите страницу с полным reload (Ctrl+F5). Если крутится несколько инстансов сервера — убедитесь, что у всех общая `server/data/`.

**Загрузил фото — 404**  
Проверьте, что файл есть в `images/uploads/` на том же сервере, что отдаёт сайт.

**Товар есть в админке, но не на главной**  
Проверьте галочку «Показывать на сайте».

**Нужна ли правка `js/products.js`?**  
Для обычной работы — нет. Файл остаётся запасным fallback, если API недоступен. Источник истины — CMS.

**Можно ли вернуть данные к заводским?**  
Удалите `server/data/cms.json` и перезапустите сервер — подтянется `server/cms-seed.json`. Заказы при этом не трогаются.

**Все ли страницы можно править из админки?**  
Да, в привычном смысле управления сайтом: вкладка **Страницы** — все ключевые картинки (баннер, о нас, контакты, фон каталога, внутренние страницы, логотип); **Тексты сайта** — заголовки блоков главной и контакты; товары / новости / отзывы / акции — в своих разделах. Длинные статьи-гайды и юридические тексты по-прежнему в HTML-файлах, но их верхний фон меняется вместе с «Фоном внутренних страниц».

**Фото сами сжимаются при загрузке?**  
Да. В товарах, новостях и акциях: поворот по EXIF, длинная сторона ≤ 1600 px, обычно WebP (PNG с прозрачностью может остаться PNG). Во вкладке **Страницы** любой JPG/PNG/GIF/WebP **всегда** сохраняется как WebP, старый загруженный файл удаляется.
