# Как выложить сайт northmp.su на Beget — для чайников

Эта инструкция **без сложных терминов**. Если что-то непонятно — идите по шагам сверху вниз, не перескакивая.

---

## Что мы делаем простыми словами

1. Арендуем у Beget **маленький сервер** (VPS) — это как отдельный компьютер в интернете.
2. Кладём туда **наш сайт с заказами** (это не Tilda, а программа на Node.js).
3. Говорим домену **northmp.su**: «открывай этот сервер, а не Tilda».
4. Включаем **защищённое соединение** (HTTPS, замочек в браузере).

**Сейчас:** при открытии northmp.su показывается Tilda («Domain has been assigned»).  
**После:** будет наш магазин с корзиной, оплатой и админкой.

---

## Что понадобится заранее

- [ ] Логин и пароль от **Beget** ([cp.beget.com](https://cp.beget.com/))
- [ ] Доступ к **Tilda** (чтобы отвязать домен)
- [ ] Доступ к **ЮKassa** (для приёма оплат)
- [ ] Файл **`.env`** с паролями и ключами (если уже настраивали сайт с разработчиком)
- [ ] **1–2 часа** спокойного времени

> **Важно:** обычный «хостинг для сайта» на Beget (где лежат PHP-сайты) **не подходит**. Нужен именно **VPS**.

---

# ШАГ 1. Заказать VPS в Beget

1. Зайдите на [cp.beget.com](https://cp.beget.com/) и войдите в аккаунт.
2. В меню найдите раздел **«Облако»** → **«VPS»** (или «Виртуальные серверы»).
3. Нажмите **«Создать»** / **«Заказать»**.
4. Выберите:
   - **Система:** Ubuntu 22.04 или 24.04
   - **Память:** минимум 1 GB (лучше 2 GB)
   - **Диск:** 10 GB хватит
5. Оплатите и дождитесь, пока сервер создастся (обычно 5–15 минут).
6. **Запишите на бумажку:**
   - **IP-адрес** сервера (выглядит как `185.123.45.67`)
   - **Пароль root** (или как подключаться по SSH — Beget покажет в карточке VPS)

---

# ШАГ 2. Подключиться к серверу

«Подключиться» = зайти на удалённый компьютер и давать ему команды.

### На Windows
1. Скачайте **PuTTY** или откройте **Windows Terminal**.
2. Команда (подставьте свой IP):
   ```
   ssh root@185.123.45.67
   ```
3. На вопрос «Are you sure?» напишите `yes` и Enter.
4. Введите пароль от VPS (при вводе символы **не видны** — это нормально).

### На Mac
1. Откройте **Терминал** (Программы → Утилиты).
2. Та же команда:
   ```
   ssh root@185.123.45.67
   ```

Если видите строку вроде `root@server:~#` — **вы внутри сервера**, всё ок.

---

# ШАГ 3. Установить программы на сервер

**Копируйте блоки целиком**, вставляйте в терминал, нажимайте Enter. Ждите окончания каждого блока.

### Блок A — обновление и базовые программы
```bash
apt update && apt upgrade -y
apt install -y curl git nginx
```

### Блок B — Node.js (движок нашего сайта)
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs
node -v
```
Должно показать `v20.x.x`.

### Блок C — PM2 (чтобы сайт не падал и сам перезапускался)
```bash
npm install -g pm2
```

---

# ШАГ 4. Скачать сайт на сервер

```bash
mkdir -p /var/www
cd /var/www
git clone https://github.com/samoilovjob-max/NMP.git nmp
cd nmp
npm install
```

Установка может занять **2–5 минут** — не закрывайте окно.

---

# ШАГ 5. Настроить секреты (.env)

Это файл с паролями. **Никому не показывайте и не выкладывайте в интернет.**

```bash
cd /var/www/nmp
cp .env.example .env
nano .env
```

Откроется редактор. Заполните **своими** значениями (пример):

```
PUBLIC_BASE_URL=https://northmp.su
PORT=3000

ADMIN_USER=admin
ADMIN_PASSWORD=ПридумайтеСложныйПароль123!
ADMIN_TOKEN=любая-длинная-случайная-строка-2026

CDEK_ACCOUNT=ваш_логин_сдэк
CDEK_SECURE=ваш_пароль_сдэк

YOOKASSA_SHOP_ID=1420560
YOOKASSA_SECRET_KEY=live_ваш_ключ
PAYMENTS_DEMO=false

YANDEX_METRICA_ID=111532214
ANALYTICS_REQUIRE_CONSENT=true

TELEGRAM_BOT_TOKEN=если_нужен
TELEGRAM_CHAT_ID=если_нужен
```

**Как сохранить в nano:**
- `Ctrl + O` → Enter (сохранить)
- `Ctrl + X` (выйти)

---

# ШАГ 6. Запустить сайт

```bash
cd /var/www/nmp
pm2 start server/index.js --name nmp
pm2 save
pm2 startup
```

После `pm2 startup` появится **длинная команда** с `sudo env ...` — **скопируйте её целиком**, вставьте, Enter.

### Проверка «сайт жив на сервере»
```bash
curl -I http://127.0.0.1:3000/
```
В ответе должно быть `HTTP/1.1 200 OK`.

---

# ШАГ 7. Настроить nginx (чтобы сайт открывался по домену)

### 7.1. Создать файл настроек
```bash
nano /etc/nginx/sites-available/northmp.su
```

Вставьте **целиком** (ничего не меняйте, кроме того что уже правильно):

```nginx
server {
    listen 80;
    server_name northmp.su www.northmp.su;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        client_max_body_size 12m;
    }
}
```

Сохранить: `Ctrl+O`, Enter, `Ctrl+X`.

### 7.2. Включить настройки
```bash
ln -sf /etc/nginx/sites-available/northmp.su /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t
systemctl reload nginx
```

Если `nginx -t` пишет **syntax is ok** — хорошо.

---

# ШАГ 8. Включить HTTPS (замочек в браузере)

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d northmp.su -d www.northmp.su
```

Certbot спросит:
- **Email** — ваш email (для продления сертификата)
- Согласие с условиями — **Y**
- Redirect на HTTPS — выберите **2** (рекомендуется)

---

# ШАГ 9. Привязать домен в Beget

1. Зайдите на [cp.beget.com](https://cp.beget.com/)
2. **Домены и поддомены** → найдите **northmp.su**
3. Откройте **«Управление DNS»** / **«Редактировать DNS-зону»**
4. Сделайте так:

| Тип | Имя (хост) | Куда указывает |
|-----|------------|----------------|
| **A** | `@` | **IP вашего VPS** (из шага 1) |
| **A** | `www` | **тот же IP** |

5. **Удалите** старые записи, которые ведут на Tilda или непонятные IP (если не уверены — спросите поддержку Beget).
6. **Сохраните.**

⏳ Подождите **15–60 минут** (иногда до 24 часов). DNS обновляется не мгновенно.

### Как проверить, что DNS уже работает
На своём компьютере в терминале:
```bash
ping northmp.su
```
IP в ответе должен совпадать с IP вашего VPS.

---

# ШАГ 10. Отвязать Tilda

1. Зайдите на [tilda.cc](https://tilda.cc/)
2. Откройте проект, к которому был привязан northmp.su
3. **Настройки сайта → Домен**
4. **Удалите / отвяжите** домен northmp.su

Если этого не сделать — может продолжать показываться заглушка Tilda.

---

# ШАГ 11. DDoS-Guard (если пользовались)

Если сайт раньше шёл через **DDoS-Guard** (в проверке был `server: ddos-guard`):

1. Зайдите в личный кабинет DDoS-Guard
2. Найдите сайт northmp.su
3. В настройках **«Источник» / «Origin» / «Проксирование»** укажите **IP вашего VPS**
4. Сохраните

Если DDoS-Guard не используете — **пропустите** этот шаг.

---

# ШАГ 12. Настроить оплату (ЮKassa)

1. Зайдите в [yookassa.ru](https://yookassa.ru/)
2. **Настройки → HTTP-уведомления**
3. Адрес (URL):
   ```
   https://northmp.su/api/payments/webhook
   ```
4. Включите события:
   - `payment.succeeded`
   - `payment.canceled`
5. Сохраните

---

# ШАГ 13. Проверить, что всё работает

Откройте в браузере по очереди:

| Ссылка | Что должно быть |
|--------|-----------------|
| https://northmp.su/ | Главная магазина, **не Tilda** |
| https://northmp.su/admin.html | Страница входа в админку |
| https://northmp.su/robots.txt | Текст с `Sitemap:` |
| https://northmp.su/privacy.html | Политика конфиденциальности |

**Баннер cookies:** нажмите «Принять» — так включается Яндекс.Метрика.

**Тест заказа:** добавьте товар в корзину → оформите → проверьте оплату (можно минимальную сумму).

# Если что-то сломалось

### «Domain has been assigned» (Tilda)
→ Не выполнен шаг 10 или DNS ещё не обновился. Подождите и проверьте шаг 9.

### Сайт не открывается вообще
На сервере выполните:
```bash
pm2 status
pm2 restart nmp
systemctl status nginx
```
В `pm2 status` у `nmp` должно быть **online**.

### Ошибка 502
Сайт на сервере не запущен. Снова:
```bash
cd /var/www/nmp
pm2 restart nmp
```

### Оплатили, но статус заказа не меняется
→ Проверьте шаг 12 (webhook ЮKassa).

### Забыли пароль от админки
→ Поменяйте `ADMIN_PASSWORD` в `.env` на сервере и перезапустите:
```bash
nano /var/www/nmp/.env
pm2 restart nmp
```

# Как обновить сайт после правок в коде

```bash
ssh root@ВАШ_IP
cd /var/www/nmp
git pull
npm install
pm2 restart nmp
```

Если меняли только тексты/товары **через админку** — ничего делать не нужно, изменения уже на сайте.

---

# Что нельзя удалять на сервере

| Папка | Что там |
|-------|---------|
| `/var/www/nmp/server/data/` | Заказы и каталог |
| `/var/www/nmp/images/uploads/` | Фото, загруженные в админке |
| `/var/www/nmp/.env` | Все пароли и ключи |

Без них потеряете заказы и настройки.
