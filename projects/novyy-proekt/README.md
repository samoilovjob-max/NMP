## Запуск

Локально: `npm start` → [http://localhost:3000/projects/novyy-proekt/](http://localhost:3000/projects/novyy-proekt/)

На проде (после деплоя корня репозитория): `https://northmp.su/projects/novyy-proekt/`

## Следующие шаги

1. Переименовать папку, если название «novyy-proekt» больше не подходит.
2. Добавить уникальные изображения в `projects/<имя>/images/` или в общую папку `images/`.
3. При необходимости завести отдельную UTM-кампанию в `direct-campaigns.json`.
