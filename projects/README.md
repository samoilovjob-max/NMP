# Подпроекты Northern Magical Place

Здесь живут отдельные инициативы бренда: лендинги, пилоты, партнёрские витрины и эксперименты, которые развиваются независимо от основного магазина на [northmp.su](https://northmp.su/).

## Структура

```
projects/
  README.md              ← этот файл
  novyy-proekt/          ← стартовый подпроект (шаблон)
    README.md
    index.html
```

## Как добавить подпроект

1. Скопируйте папку `novyy-proekt` и переименуйте (латиница, через дефис):  
   `cp -R projects/novyy-proekt projects/moy-proekt`
2. Отредактируйте `README.md` — опишите цель, аудиторию и KPI.
3. Замените заглушки в `index.html` на реальный контент.
4. При необходимости подключите общие стили и логотип из корня репозитория (`../../css/styles.css`, `../../images/…`).

## Локальный просмотр

Подпроекты отдаются тем же сервером, что и основной сайт:

```bash
npm install
npm start
```

Откройте, например: **http://localhost:3000/projects/novyy-proekt/**

## Связь с основным сайтом

| Что | Где |
|-----|-----|
| Магазин, CMS, заказы | корень репозитория |
| Админка | `/admin.html` |
| Документация | `docs/` |

Подпроекты **не дублируют** каталог и оплату, пока вы явно не интегрируете их с CMS или не вынесете в отдельный репозиторий.
