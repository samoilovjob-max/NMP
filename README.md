# Northern Magical Place

Премиальный лендинг карельских разборных костровых систем Flat-Pack.

Сайт: [http://northmp.su/](http://northmp.su/)

## Страницы

- `index.html` — главная (герой, преимущества, каталог, стиль жизни, о нас, отзывы, FAQ, контакты)
- `buyers.html` — доставка, сроки, возврат и обмен
- `privacy.html` — политика конфиденциальности

## Запуск локально

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080
