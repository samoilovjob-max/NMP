# Northern Magical Place

Премиальный сайт карельских костровых систем Flat-Pack + заказ через СДЭК / ЮKassa.

Сайт: [https://northmp.su/](https://northmp.su/)

**Админка CMS:** [`/admin.html`](admin.html) — товары, цены, фото, новости, отзывы, акции, тексты, заказы.  
**Инструкция:** [`docs/UPRAVLENIE-SAJTOM.md`](docs/UPRAVLENIE-SAJTOM.md)  
**Деплой на northmp.su (Beget):** [`docs/DEPLOY-NORTHMP-BEGET.md`](docs/DEPLOY-NORTHMP-BEGET.md)  
**Деплой для чайников (Beget):** [`docs/DEPLOY-BEGET-DLYA-CHAYNIKOV.md`](docs/DEPLOY-BEGET-DLYA-CHAYNIKOV.md)

## Запуск

```bash
cp .env.example .env   # заполните ключи
npm install
npm start
```

Откройте: **http://localhost:3000**

> Важно: открывайте сайт через `npm start` (порт 3000), а не как HTML-файл.

## Админка заказов

Откройте: **http://localhost:3000/admin.html**

Войдите логином и паролем из `.env` → `ADMIN_USER` / `ADMIN_PASSWORD`.

В админке видно:
- какой товар / артикул куплен
- оплату и срок отгрузки (`SHIP_SLA_HOURS`, по умолчанию 48 ч)
- ПВЗ, трек СДЭК, заметки
- действия: отметить оплату, создать накладную, «сдан в СДЭК», «прибыл»

## Карта ПВЗ (OpenStreetMap)

Карта пунктов выдачи работает на **Leaflet + OpenStreetMap** — бесплатно, без API-ключей.

На чекауте: кнопка «Показать карту ПВЗ» → маркеры СДЭК → выбор ПВЗ кликом.  
Список ПВЗ под картой остаётся как запасной способ выбора.

## ЮKassa — боевой режим

**Smart Payment + redirect + webhook.**

1. В `.env`:

```env
YOOKASSA_SHOP_ID=1420560
YOOKASSA_SECRET_KEY=live_...
PAYMENTS_DEMO=false
PUBLIC_BASE_URL=https://northmp.su
```

2. В ЮKassa → Настройки → HTTP-уведомления:
   `https://northmp.su/api/payments/webhook`
   События: `payment.succeeded`, `payment.canceled`

### Почему так

- Секрет ЮKassa **только на сервере** (не в браузере)
- Цена пересчитывается по серверному каталогу (нельзя подменить сумму)
- После оплаты webhook ставит статус «оплачен», считает дедлайн отгрузки и создаёт накладную СДЭК
- Клиент возвращается в личный кабинет; если вкладку закрыл — webhook всё равно завершит заказ

Если ключей ЮKassa нет — временно включите `PAYMENTS_DEMO=true` для локальных тестов без оплаты.

## Яндекс.Метрика и Google Analytics

1. Создайте счётчик в [Яндекс.Метрике](https://metrika.yandex.ru/) и ресурс GA4 в [Google Analytics](https://analytics.google.com/).
2. В `.env`:

```env
YANDEX_METRICA_ID=111532214
GA_MEASUREMENT_ID=G-XXXXXXXXXX
ANALYTICS_REQUIRE_CONSENT=true
```

3. Перезапустите сервер (`npm start`).

**Два режима уведомления посетителя:**

| `ANALYTICS_REQUIRE_CONSENT` | Что видит пользователь |
|-----------------------------|------------------------|
| `true` (рекомендуется) | Баннер «Принять / Только необходимые» до загрузки счётчиков |
| `false` | Метрика грузится сразу + компактная информационная полоска внизу (можно закрыть) |

В обоих режимах в футере есть ссылка **«Cookies и аналитика»** — пользователь может снова открыть настройки. Подробности — в `privacy.html` (раздел 12).

4. E-commerce события: просмотр товара, начало checkout, покупка (демо и возврат с оплаты).
