# Northern Magical Place

Премиальный сайт карельских костровых систем Flat-Pack + заказ через СДЭК.

Сайт: [http://northmp.su/](http://northmp.su/)

## Запуск (обязательно для СДЭК)

1. Скопируйте `.env.example` → `.env` и заполните ключи СДЭК
2. Установите зависимости и запустите сервер:

```bash
npm install
npm start
```

Откройте: **http://localhost:3000**

> Важно: открывайте сайт именно через `npm start` (порт 3000), а не как простой HTML-файл. Иначе API СДЭК не будет работать.

## Что уже подключено

- Поиск города через API СДЭК
- Список пунктов выдачи (ПВЗ)
- Расчёт стоимости и сроков доставки
- Создание накладной СДЭК после оформления заказа
- Трекинг статуса в личном кабинете
- Карта виджета СДЭК — после добавления `YANDEX_MAPS_API_KEY` в `.env`

## Безопасность

`Account` и `Secure password` хранятся только в `.env` на сервере и **не попадают в Git**.

Если ключи когда-либо светились в чате/публичном месте — лучше перевыпустить их в кабинете СДЭК.
