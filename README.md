# Northern Magical Place

Премиальный сайт карельских костровых систем Flat-Pack + заказ через СДЭК / ЮKassa.

Сайт: [http://northmp.su/](http://northmp.su/)

## Запуск

```bash
cp .env.example .env   # заполните ключи
npm install
npm start
```

Откройте: **http://localhost:3000**

> Важно: открывайте сайт через `npm start` (порт 3000), а не как HTML-файл.

## Админка заказов

Откройте: **http://localhost:3000/admin.html**

Войдите токеном из `.env` → `ADMIN_TOKEN`.

В админке видно:
- какой товар / артикул куплен
- оплату и срок отгрузки (`SHIP_SLA_HOURS`, по умолчанию 48 ч)
- ПВЗ, трек СДЭК, заметки
- действия: отметить оплату, создать накладную, «сдан в СДЭК», «прибыл»

## Карта ПВЗ (Яндекс.Карты)

1. Создайте ключ **JavaScript API и HTTP Геокодер** на [developer.tech.yandex.ru](https://developer.tech.yandex.ru/services/)
2. Вставьте в `.env`:

```env
YANDEX_MAPS_API_KEY=ваш_ключ
```

3. Перезапустите `npm start`

Без ключа работает список ПВЗ СДЭК (без карты).

## ЮKassa — рекомендуемый вариант

**Лучший сценарий для этого сайта: Smart Payment + redirect + webhook.**

1. В кабинете ЮKassa возьмите `shopId` и **секретный ключ**
2. Пропишите в `.env`:

```env
YOOKASSA_SHOP_ID=...
YOOKASSA_SECRET_KEY=...
PAYMENTS_DEMO=false
PUBLIC_BASE_URL=https://ваш-домен.ru
```

3. В ЮKassa → Настройки → HTTP-уведомления укажите:
   `https://ваш-домен.ru/api/payments/webhook`
   События: `payment.succeeded`, `payment.canceled`

### Почему так

- Секрет ЮKassa **только на сервере** (не в браузере)
- Цена пересчитывается по серверному каталогу (нельзя подменить сумму)
- После оплаты webhook ставит статус «оплачен», считает дедлайн отгрузки и создаёт накладную СДЭК
- Клиент возвращается в личный кабинет; если вкладку закрыл — webhook всё равно завершит заказ

Пока ключей ЮKassa нет, сайт работает в **демо-оплате** (`PAYMENTS_DEMO=true`): заказ и СДЭК создаются сразу, чтобы можно было тестировать админку.
