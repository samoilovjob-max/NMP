# DXF v2 для проверки сборки

## Важно
Это НЕ три одинаковые копии. Комплект комплементарный:
- `bokovoy-1.dxf` — исходный контур элемента 1
- `bokovoy-2.dxf` — исходный контур элемента 2 (другой)
- `bokovoy-3.dxf` — замыкающая деталь: зеркало элемента 1 по Y (не копия), с более плотным пазом

## Что изменено
1. Краевые стыковочные пазы (рот паза) сужены: **5.50 → 3.50 мм** (на 1 и 2)
2. На замыкающей 3-й: рот паза **3.40 мм** (чуть плотнее)
3. Внутренние тонкие пазы унифицированы до **3.10 мм**
4. Элемент 3 больше не узкий (334 мм) — габарит как у 1: ~348.6×306.3

## Порядок сборки (по видео)
1. Соединить bokovoy-1 + bokovoy-2
2. Замкнуть bokovoy-3 сверху в оба паза
3. Поставить verh-1 или verh-4

## Критерий теста
- 3-я стенка входит с лёгким натягом (не проваливается)
- После сборки нет качания
- Разборка без заедания молотком

## Если всё ещё люфт
Сообщите фактическую толщину металла — ужмём рот паза ещё (например до 3.30).
Если 3-я не стыкуется с 2-й — нужен другой вариант замыкающей (зеркало от 2).
